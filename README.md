# VIP Studio

A macOS workspace for discovering and downloading Hongguo short dramas, browsing a local episode library, and extracting/reviewing subtitles.

**Download:** [GitHub Releases](https://github.com/reachhwasup/vip_studio/releases)

Requires Apple Silicon and macOS 26 or later. Install version 1.2.0 once; subsequent releases can be installed through **VIP Studio → Check for Updates**.

## Features

- Trending catalogue, episode downloads and shared posters
- Local library with playback, history and download-folder selection
- On-device subtitle OCR, SRT regeneration, backups and a timing/text editor
- Native macOS notifications
- Signed in-app updates using Sparkle and GitHub Releases

See [macOS build and release instructions](macos/README.md). Settings, device credentials and downloaded media are not included in this repository or release bundle.
