Import & export

Subtitle files

Preview timed captions from SRT, WebVTT, ASS / SSA, or JSON. Original timestamps are preserved until you apply a timing adjustment below.

UTF-8, UTF-16, GB18030 and Big5 are supported. Plain text without timings cannot be imported.
Synchronize subtitle timing

For captions that gradually run ahead or behind, set the desired last caption end. All timestamps stretch or compress proportionally. Use offset for a fixed delay (positive = later). The target end includes the offset. Dialogue may end before the video does.

JSON preserves both the original text and translation. Other formats export the caption text. Importing previews a file here; it does not replace subtitles saved with a video.

How captions are cleaned up

Speaker tags and recurring speaker prefixes are recognised. Styling, comments, drawings and sound-only captions are removed. Empty captions, duplicates at the same moment and invalid timings are skipped. Captions longer than 30 seconds are shortened to 30 seconds.

Changes to subtitles apply to upcoming downloads.
